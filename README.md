# Node.js Practice

This is a simple Node.js practice project created for learning the basics of JavaScript runtime behavior, script execution, and working with Node.js in a small project setup.

## Project Overview

The project currently contains a basic entry file that prints a greeting to the console. It is designed as a starting point for learning Node.js fundamentals before moving on to more advanced topics like:

- async/await
- file handling
- npm packages
- APIs and servers
- Express.js

## Requirements

Before running this project, make sure you have the following installed:

- Node.js
- npm (usually comes bundled with Node.js)

## Getting Started

1. Open the project folder in your terminal.
2. Run the following command:

```bash
node index.js
```

3. You should see the output:

```bash
hello abdul kadir khan
```

- `index.js` — main JavaScript file that runs the project
- `package.json` — project metadata and scripts
- `package-lock.json` — dependency lock file generated by npm
